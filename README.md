# 📱 Тіркелу және авторизация мобильді қосымшасы

## 📌 Жоба туралы

Бұл жоба React Native және Expo технологиялары арқылы жасалған мобильді қосымша интерфейсі болып табылады.

Қосымшаның негізгі мақсаты — пайдаланушыларға жүйеге кіру, жаңа аккаунт тіркеу, құпиясөзді қалпына келтіру және өз қаласын таңдау мүмкіндіктерін ұсыну.

Қосымшаның интерфейсі қарапайым әрі түсінікті етіп жасалған. Дизайнда ақ фон, күлгін түсті батырмалар және дөңгеленген енгізу өрістері қолданылады.

## 🎯 Жобаның мақсаты

- Пайдаланушыға ыңғайлы мобильді интерфейс жасау.
- Тіркелу және жүйеге кіру экрандарын құру.
- Құпиясөзді қалпына келтіру интерфейсін жасау.
- SMS кодын енгізу экранын әзірлеу.
- Пайдаланушыға қаланы таңдау мүмкіндігін беру.
- React Native технологиясымен жұмыс істеуді үйрену.

## 🛠 Қолданылған технологиялар

- **React Native** — мобильді қосымшаның интерфейсін жасау үшін.
- **React** — компоненттер мен күйді басқару үшін.
- **Expo** — қосымшаны іске қосу және тестілеу үшін.
- **TypeScript** — жобаның негізгі файлында қолданылады.
- **JavaScript** — компоненттердің логикасын жазу үшін.
- **StyleSheet** — интерфейстің дизайнын реттеу үшін.

## 📲 Қосымшаның мүмкіндіктері

### 1. Жүйеге кіру
Пайдаланушы телефон нөмірі мен құпиясөзді енгізе алатын экран.

Мүмкіндіктері:
- Телефон нөмірін енгізу.
- Құпиясөзді енгізу.
- Құпиясөзді қалпына келтіру бөліміне өту.
- Тіркелу экранына ауысу.

### 2. Құпиясөзді қалпына келтіру
Пайдаланушы телефон нөмірін енгізіп, құпиясөзді қалпына келтіру процесін бастайды.

### 3. Телефон нөмірін растау
Пайдаланушыға SMS арқылы жіберілген кодты енгізуге арналған экран.

Мүмкіндіктері:
- Төрт таңбалы кодты енгізу.
- Кодты қайта сұрату интерфейсі.
- Келесі экранға өту.

### 4. Жаңа құпиясөз орнату
Пайдаланушы жаңа құпиясөзді екі рет енгізе алатын экран.

Мүмкіндіктері:
- Жаңа құпиясөз енгізу.
- Құпиясөзді қайта енгізу.
- Жүйеге кіру экранына қайту.

### 5. Тіркелу
Жаңа пайдаланушыға аккаунт ашуға арналған экран.

Енгізілетін мәліметтер:
- Пайдаланушының аты.
- Телефон нөмірі.
- Құпиясөз.

Сонымен қатар пайдаланушы пайдалану шарттарымен келісетінін белгілей алады.

### 6. Қаланы таңдау
Пайдаланушы өз қаласын таңдайтын экран.

Қолжетімді қалалар:
- Алматы
- Астана
- Шымкент
- Қарағанды
- Ақтөбе

Қаланы таңдау тізім арқылы жүзеге асырылады.

## 🎨 Интерфейс дизайны

Қосымшаның дизайны қарапайым және заманауи стильде жасалған.

Негізгі дизайн элементтері:
- Ақ түсті фон.
- Күлгін түсті батырмалар.
- Дөңгеленген енгізу өрістері.
- Экран тақырыптары мен түсіндірме мәтіндері.
- Артқа қайту батырмасы.
- Экрандар арасында ауысу мүмкіндігі.
